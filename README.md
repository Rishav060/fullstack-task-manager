# 🚀 Full Stack Task Manager

A simple full-stack Task Manager web application where users can add and delete tasks.

---

## 🧠 Features

- Add new tasks
- Delete tasks
- Data stored in database (persistent)
- Clean and responsive UI

---

## ⚙️ Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MySQL

---

## 🔗 How It Works

- Frontend sends requests using `fetch()`
- Backend handles API using Express
- Data is stored and retrieved from MySQL
